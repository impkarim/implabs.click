**Services:**

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Build Tool:** Vite
- **Routing:** React Router
- **Icons:** Lucide React
- **Deployment:** GitHub Pages

## Features

- Bilingual support (English / Arabic) with smooth language transitions
- Dark mode with system preference detection and manual toggle
- Responsive design across all devices
- Professional monochrome design system
- Animated components and micro-interactions
- SEO optimized with structured data (JSON-LD)
- Accessibility-first approach (WCAG compliant)
- Fast loading with optimized production builds

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/       # Reusable UI components
├── pages/            # Route pages
├── i18n/             # Translations and language context
├── assets/           # Static assets
├── App.tsx           # Main app with routing
├── main.tsx          # Entry point
└── index.css         # Global styles and animations
```
